License Saver for Jira

Security Policy

Last updated: 27 October 2026

Architecture

  • License Saver runs entirely on Atlassian Forge. Marouani Apps operates no servers, databases or third-party services for the app.
  • All app data is stored in Atlassian Forge storage for the customer's installation. We have no access to it.
  • The only outbound destination is api.atlassian.com (the Atlassian Administration API).
  • The app's page is available only to Jira administrators.

Secrets

The organization API key provided by the customer's organization admin is stored with Forge's encrypted secret storage (kvs.setSecret), is never returned to the browser, and is never logged. Customers can revoke it at any time in Atlassian Administration → Settings → API keys.

Logging

Application logs (kept by Atlassian Forge) contain only technical information such as counts and status codes — no names, email addresses or account IDs.

Safety controls

  • Every suspend and restore is recorded in an in-app activity log with one-click restore.
  • Automatic mode is off by default and limited to 25 users and 10% of users per day; new users, recently restored users and users with open assigned issues are skipped.

Reporting a vulnerability

Please email mohamedhabibmarouani8@gmail.com with the subject “Security report – License Saver”. We acknowledge reports within 2 business days, keep you informed while we investigate, and fix confirmed issues as a priority. Please don't publicly disclose an issue before we've had a chance to address it.

Incident response

If a security incident affects customer data, we will notify affected customers and Atlassian without undue delay, in line with the Atlassian Marketplace Partner Agreement and applicable law (including GDPR).
