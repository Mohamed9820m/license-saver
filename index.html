Setup in 5 minutes

  1. Install License Saver from the Atlassian Marketplace and open Jira settings → Apps → License Saver.
  2. In admin.atlassian.com, go to Settings → API keys and create a key without scopes (Atlassian only allows suspending and restoring users with this key type).
  3. Paste your Organization ID and key in the app's Settings tab, enter your price per user, and click Scan users.
